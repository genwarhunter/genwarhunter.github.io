Privacy Policy

Last updated: October 5, 2026

Overview

Obsidian Calendar is a personal application that connects Obsidian with Google Calendar.

Google Data

The application accesses Google Calendar data only to provide calendar synchronization and display features requested by the user.

Depending on the enabled functionality, the application may access calendar names, calendar events, event titles, dates, times, locations, descriptions, reminders, and event identifiers.

How data is used

Google Calendar data is used only to create, read, update, delete, synchronize, and display calendar events between Obsidian and Google Calendar.

Data storage

The application stores the identifiers and metadata required to maintain synchronization between Obsidian notes and Google Calendar events.

The application does not sell Google user data and does not use Google user data for advertising.

Data sharing

Google user data is not sold or shared with third parties, except where necessary to provide the functionality described above or where required by law.

Data security

Authentication is performed using Google's OAuth 2.0 authorization system. The application does not request or store the user's Google password.

Revoking access

The user can revoke the application's access to their Google Account at any time through their Google Account settings.
